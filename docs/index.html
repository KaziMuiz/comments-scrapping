multiplayer single-player

Before looking at the results we wrote down four guesses. The findings page tests them one at a time, and the action plan page turns the results into something a developer or a player can use.

How this site fits together

  • The research (The data, Findings, Action plan, Explore) is built from 2000 reviews collected from five games and saved in the project.
  • The tool (Try any game) runs the same analysis on any Steam game, live.
  • The support pages (Cautions, Q&A) explain the limits of the work and answer likely questions.

How the data was collected

Every review comes from Steam's public review endpoint. A Python script asked for reviews, followed Steam's page markers to the next batch, and saved the results to a file anyone can open.

  1. 1

    Collect

    100 reviews per request, the 400 most recent English reviews for each game, with a pause between requests so the script stays polite.

  2. 2

    Clean

    Duplicates are removed using each review's unique ID, and every game is saved to its own file as soon as it finishes.

  3. 3

    Analyze

    For each review the script measures its length, checks it for eight problem themes and four praise themes (such as cheating, price, story and visuals) and notes how many hours the reviewer had played.

  4. 4

    Show

    The analysis writes a small summary file, and this page reads it to draw everything you see below.

    What to do with these findings

    A developer cannot read thousands of reviews, and a new player does not want to. Pick a game to see which problems come up most in its negative reviews and what players praise.

    All games at a glance

    Each cell shows the share of a game's negative reviews that mention that problem. Brighter cells mean more complaints.

    The suggestions come from how often players mention each problem. They show where complaints concentrate, not that a fix would raise the ratings.

    Try it on any game

    Paste a Steam link, enter a game ID, or type a game name. The tool reads the game's most recent English reviews, finds the problems players mention most, and shows example comments for each one.

    This page works when you start the project server with py src/app.py and open http://127.0.0.1:8000. It cannot run on the published website, because that hosts only fixed pages and the tool needs Python to read the reviews.
